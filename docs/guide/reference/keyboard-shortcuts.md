---
title: Keyboard shortcuts
summary: The default keys for files, views, writing and navigation, and how to change them.
---

These are the default shortcuts. Every one can be changed in Settings ▸ **Shortcuts** or **View** ▸ **Keyboard Shortcuts…**; the native menus follow your changes.

## When to use it

- When you want to work faster from the keyboard.
- When a shortcut clashes with another app and you want to change it.

## How to use it

### Files and windows

| Keys | Does |
|---|---|
| <kbd>⌘</kbd> <kbd>K</kbd> | Command and file palette |
| <kbd>⌘</kbd> <kbd>N</kbd> / <kbd>⌘</kbd> <kbd>T</kbd> | New file / new tab |
| <kbd>⌘</kbd> <kbd>⌥</kbd> <kbd>N</kbd> | New from Template |
| <kbd>⌃</kbd> <kbd>⌘</kbd> <kbd>N</kbd> | Quick Note |
| <kbd>⌘</kbd> <kbd>⇧</kbd> <kbd>D</kbd> | Open Daily Note |
| <kbd>⌘</kbd> <kbd>⇧</kbd> <kbd>N</kbd> | New window |
| <kbd>⌘</kbd> <kbd>O</kbd> / <kbd>⌘</kbd> <kbd>⇧</kbd> <kbd>O</kbd> | Open file / open folder |
| <kbd>⌃</kbd> <kbd>⌘</kbd> <kbd>O</kbd> | Switch Workspace |
| <kbd>⌘</kbd> <kbd>S</kbd> / <kbd>⌘</kbd> <kbd>⇧</kbd> <kbd>S</kbd> | Save / Save As |
| <kbd>⌘</kbd> <kbd>W</kbd> | Close tab |
| <kbd>⌘</kbd> <kbd>,</kbd> | Settings |

| Keys | Does |
|---|---|
| <kbd>⌘</kbd> <kbd>B</kbd> | Show or hide the Explorer |
| <kbd>⌘</kbd> <kbd>P</kbd> | Show or hide the preview |
| <kbd>⌘</kbd> <kbd>E</kbd> | Reading view (Edit PDF in a PDF) |
| <kbd>⌘</kbd> <kbd>⌥</kbd> <kbd>O</kbd> | Outline |
| <kbd>⌘</kbd> <kbd>⌥</kbd> <kbd>⇧</kbd> <kbd>O</kbd> | Links |
| <kbd>⌘</kbd> <kbd>⌥</kbd> <kbd>⇧</kbd> <kbd>F</kbd> | Filter |
| <kbd>⌃</kbd> <kbd>⇧</kbd> <kbd>G</kbd> | Source Control |
| <kbd>⌃</kbd> <kbd>⌘</kbd> <kbd>Z</kbd> | Focus mode |
| <kbd>⌘</kbd> <kbd>⌥</kbd> <kbd>T</kbd> | Typewriter scrolling |
| <kbd>⌘</kbd> <kbd>⇧</kbd> <kbd>P</kbd> | Present |
| <kbd>⌘</kbd> <kbd>⌥</kbd> <kbd>⇧</kbd> <kbd>P</kbd> | Present from current slide |
| <kbd>⌘</kbd> <kbd>+</kbd> / <kbd>⌘</kbd> <kbd>−</kbd> / <kbd>⌘</kbd> <kbd>0</kbd> | Zoom in / out / reset |
| <kbd>⌃</kbd> <kbd>⌘</kbd> <kbd>F</kbd> | Full screen |

### Writing

| Keys | Does |
|---|---|
| <kbd>⌘</kbd> <kbd>⇧</kbd> <kbd>X</kbd> | Toggle task |
| <kbd>⌘</kbd> <kbd>⌥</kbd> <kbd>L</kbd> | Insert link to note |
| <kbd>⌘</kbd> <kbd>⌥</kbd> <kbd>K</kbd> | Insert citation |
| <kbd>⌘</kbd> <kbd>⇧</kbd> <kbd>E</kbd> | Save excerpt |
| <kbd>⌘</kbd> <kbd>⌥</kbd> <kbd>⇧</kbd> <kbd>V</kbd> | Paste as plain text |
| <kbd>⌘</kbd> <kbd>Return</kbd> | Insert table row below |

### Find and move around

| Keys | Does |
|---|---|
| <kbd>⌘</kbd> <kbd>F</kbd> | Find in the note or PDF |
| <kbd>⌘</kbd> <kbd>⇧</kbd> <kbd>F</kbd> | Find in Folder |
| <kbd>⌘</kbd> <kbd>⌥</kbd> <kbd>F</kbd> | Replace in Folder |
| <kbd>⌘</kbd> <kbd>⌥</kbd> <kbd>B</kbd> | Add bookmark |
| <kbd>⌘</kbd> <kbd>⌥</kbd> <kbd>⇧</kbd> <kbd>B</kbd> | Show bookmarks |
| <kbd>⌃</kbd> <kbd>⌘</kbd> <kbd>←</kbd> / <kbd>→</kbd> | Go back / forward |

### PDF and AI

| Keys | Does |
|---|---|
| <kbd>⌘</kbd> <kbd>⇧</kbd> <kbd>A</kbd> | PDF annotations |
| <kbd>⌘</kbd> <kbd>⌥</kbd> <kbd>C</kbd> | PDF: Copy Quote |
| <kbd>V</kbd> <kbd>T</kbd> <kbd>R</kbd> <kbd>C</kbd> <kbd>I</kbd> | PDF edit tools: Select, Add Text, Replace Text, Cover, Image |
| <kbd>⌘</kbd> <kbd>⌥</kbd> <kbd>J</kbd> | New AI chat |
| <kbd>Return</kbd> / <kbd>⇧</kbd> <kbd>Return</kbd> | Send chat message / new line |

> [!NOTE]
> The palette is <kbd>⌘</kbd> <kbd>K</kbd> only; <kbd>⌘</kbd> <kbd>P</kbd> toggles the preview. Open Daily Note uses <kbd>⌘</kbd> <kbd>⇧</kbd> <kbd>D</kbd> because macOS keeps <kbd>⌥</kbd> <kbd>⌘</kbd> <kbd>D</kbd> for the Dock.

## What it will not do

- Changing a shortcut never removes the command: it stays in its menu and in <kbd>⌘</kbd> <kbd>K</kbd>.
