## FAQ

**1. What is BugText?** (16/120)

BugText is a desktop Markdown editor and document workspace. It opens a folder of Markdown, text, HTML and PDF files in one window, with a live preview, folder search, a command palette, a PDF reader with editing tools, and an optional AI panel. (245/600)

**2. Who is it for?** (14/120)

People who keep notes, documentation or project files as Markdown in folders: developers, technical writers, students and researchers who want an IDE-style layout without a heavy IDE. (183/600)

**3. Which platforms does it run on?** (31/120)

BugText is built for macOS and runs natively on Apple Silicon and Intel Macs. PDF and DOCX export need Pandoc and Typst, which you can install with `brew install pandoc typst`. The AI panel needs either a supported command-line agent or an API connection. (255/600)

**4. How much does it cost?** (22/120)

BugText is free. It is open source under the MIT license. AI providers you connect may charge for their own service. (116/600)

**5. Where are my files and settings stored?** (39/120)

Your notes stay where you put them, as plain files. Settings live in the app's configuration folder on your Mac, and API keys are kept in the macOS Keychain. BugText has no account and does not upload your files. When you use AI, the note text and passages you send go to the engine you chose. (293/600)

**6. Does it work offline? Does it sync?** (35/120)

Everything except cloud AI and update checks works offline, including PDF OCR. BugText has no sync service of its own. Because notes are normal files, you can keep the folder in iCloud Drive, Dropbox or a Git repo, and BugText reloads files that change on disk. (261/600)

**7. How do I install and update it?** (31/120)

Download the .dmg from the GitHub releases page and drag BugText to Applications. The app is not signed with an Apple Developer ID yet, so the first launch shows a Gatekeeper warning. Open System Settings ▸ Privacy & Security and click Open Anyway, then launch it again. Updates are signed and BugText always asks before installing one. Checks are manual by default; you can turn on a daily automatic check. (407/600)

**8. Can I import and export documents?** (34/120)

There is nothing to import: open any folder of .md, .txt, .html or .pdf files. Markdown documents export to PDF and Word (DOCX) with math and diagrams rendered, or to PNG and SVG images. HTML documents export to PNG and SVG. (224/600)

**9. How is it different from Obsidian or VS Code?** (45/120)

BugText has no vault format or plugin system to learn: it opens plain folders. Unlike VS Code it is built around reading and writing documents, with a rendered preview, a PDF reader and editor, and document export in the box. It does not have VS Code's extension ecosystem or Obsidian's linked-note graph. (305/600)

**10. Which AI tools does it work with?** (33/120)

BugText detects Claude Code, Codex CLI and Pi installed on your Mac. It can also connect to Anthropic, OpenAI, OpenRouter, or any OpenAI- or Anthropic-compatible server, including local models in Ollama, LM Studio and MLX. Each AI feature can use a different engine, and each can be turned off. (294/600)

**11. Can terminal agents read my notes?** (34/120)

Yes, if you turn it on. BugText includes an MCP server that lets Claude Code and Codex list, search, read, update and create notes in the folders open in the app. It is off by default, is limited to open folders, and takes a snapshot before every edit so you can undo it. (271/600)

**12. How do I report a bug or ask for a feature?** (43/120)

Open an issue at github.com/kael-wanderer/BugText/issues. Include your macOS version, the BugText version from Settings ▸ General, and the steps that cause the problem. (168/600)

## Release note

**Version:** 0.3.0

What's new:

- New name: mdFlow is now BugText, with a new icon. Settings, recent files and saved API keys from mdFlow do not carry over.
- Settings: a full-window Settings screen (⌘,) with search and General, Editing, Theme, Shortcuts and AI pages.
- AI engines: pick Claude Code, Codex CLI, Pi or an API connection, with its model and effort, for Chat and each quick action.
- Safer agents: coding agents run in a macOS sandbox limited to the open folder, and BugText lists every file they changed.
- MCP server: Claude Code and Codex can search, read and edit your open notes. Off by default; each edit is snapshotted first.
- Also new since 0.2.7: SQL highlighting, drag files between folders, interactive HTML previews and offline PDF OCR.
- Fixed: PDFs look sharp on Retina and save Vietnamese text and rotated-page edits; files reload when changed elsewhere; settings sync.
- Removed: Excalidraw boards. .excalidraw files now open as plain JSON text; open them in BugMind to keep drawing.
- Removed: jsMind mind maps. .mind files stay on disk and open as plain JSON text; no BugText or BugMind importer reads them.
- Removed: the Agent Console and built-in terminal. Run Claude Code, Codex or Pi in your own terminal app.
